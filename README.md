## 技术架构与多端优势

后端依托 FastAdmin 框架，基于 ThinkPHP 开发，自带成熟的 RBAC 权限管理、插件机制、API 管理、数据导出能力，后台 CRUD 开发高效，方便开发者扩展功能；前端使用 Uniapp 开发，一份代码编译出微信小程序与 H5 页面，学员无需下载 APP，微信扫码、浏览器打开 H5 即可进入学习答题，降低用户使用门槛。整套源码支持 LNMP 环境部署，代码交付完整，可私有化部署，学习记录、题库、学员数据全部自主存储，满足企业、驾校、培训机构的数据合规要求。后台权限精细化划分，超级管理员、题库管理员、讲师、学员等角色权限隔离，题库导入、试卷发布、成绩查看权限分开管控。

## 核心业务功能模块

### 1. 题库管理，批量导入维护

后台支持多级题库分类，可按科目、章节、专题划分题库，适配驾考科目一科目四、安全培训、职业技能题库等分类逻辑。题型覆盖单选题、多选题、判断题、填空题、简答题，支持图文题干、答案解析。支持 Excel 批量导入试题，也可单题新增编辑，题目可设置难度标签、分值，支持试题纠错、后台审核，大幅降低题库维护工作量。

### 2. 多样化刷题练习模式

学员端提供多种学习模式：章节练习，按学习进度逐章刷题；专项练习，针对薄弱考点定向训练；真题练习、顺序刷题、随机刷题；系统自动收集错题到错题本，支持错题反复练习，附带答案解析，针对性补强短板，同时支持收藏题目、添加笔记，满足自主复习需求。答题过程支持断点续答，中途退出后再次进入可以继续做题，优化移动端学习体验FastAdmin。

### 3. 智能组卷与在线考试

组卷分为固定组卷与随机组卷两种方式，管理员创建试卷时，可手动挑选题目，也可以设置题型、数量、难度，系统自动随机抽题组卷。考试支持限时作答、设置及格分数、答题次数限制、试卷有效期、题目选项乱序，模拟真实考场规则，时间截止自动交卷。客观题自动判分出分，简答题支持后台人工复核打分；支持正式考试、模拟考试、补考配置，适合企业转正考核、安全月考、驾校模拟测试、招生测评等场景。同时内置防作弊配置，可限制切屏、限定参与人员范围，保障考试公平性FastAdmin。

### 4. 网校课程学习模块

系统不只是刷题工具，同时具备网校学习能力，支持上传图文、音视频课程，课程可以设置免费观看、付费解锁、VIP 观看、卡密兑换。机构可以上架系列培训课、理论教学视频，学员先听课学习，再配套题库刷题、参加结业考试，形成 “学习 — 练习 — 考核” 闭环。配套课程评论、学习进度记录，后台查看学员课时完成情况，适合职业教育、企业线上培训网校运营。

### 5. 学员中心、成绩与数据看板

学员个人中心统一展示学习时长、刷题记录、考试记录、成绩单、错题集、证书。考试完成后自动生成成绩报告，标注错题与薄弱知识点。后台数据看板可视化展示学员参与量、刷题量、考试通过率、分数分布、热门题库等统计图表，支持按部门、班级、学员筛选，成绩明细批量导出 Excel，方便人事、培训负责人复盘培训效果，向上报送培训台账FastAdmin。

### 6. 运营配套能力

支持微信授权登录、手机号登录，H5 端可分享转发；高级版本支持会员套餐、优惠券、分销推广、电子证书生成，考试合格后自动生成可查验电子培训证书，适合需要持证上岗的安全培训、职业培训场景。消息通知可对接微信模板消息，考试提醒、成绩通知、课程更新自动推送学员。首页可视化装修，自由配置轮播图、题库入口、课程板块，打造自有品牌学习门户。
